# Goji v0.2 Operational Intelligence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a conservative, testable full-slate pregame pipeline that validates evidence, validates player props, creates canonical GENOME freeze payloads, and keeps cold-start uncertainty explicit.

**Architecture:** Add focused CARAPACE, PREYSCAN, and operational orchestration modules around the existing immutable model types, `ColdStartBaseline`, and `GenomeClient`. Preparation remains pure/in-memory; the only write is an explicit final `freeze()` call to the existing `genome_freeze_slate` RPC.

**Tech Stack:** Python 3.11, dataclasses, standard library datetime, requests, pytest 8, GitHub Actions, Supabase GENOME RPC.

**Spec:** `docs/superpowers/specs/2026-09-16-goji-v0.2-operational-intelligence.md`

## Global Constraints

- Preserve the existing SportsGameOdds -> Goji and Goji -> GENOME integrations.
- Do not create duplicate persistence.
- Keep model probability separate from market implied probability.
- `ColdStartBaseline` remains `COLD_START` + `NO_ROAR`.
- `BLOCKED` opportunities are not predictions.
- PLAYER_PROP requires player, market, numeric line, side, and confirmed expected participation.
- CARAPACE decisions are exactly `PASS`, `PASS_WITH_CAUTION`, or `BLOCKED`.
- Default freshness policy: caution after 30 minutes, block after 90 minutes, max 5 minutes positive clock skew.
- No automatic lesson/model promotion in this milestone.
