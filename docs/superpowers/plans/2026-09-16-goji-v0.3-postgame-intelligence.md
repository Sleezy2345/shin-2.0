# Goji v0.3 — Postgame Intelligence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a sport-agnostic, auditable postgame pipeline that retrieves finalized SportsGameOdds results, validates and grades frozen predictions conservatively, settles only unambiguous outcomes through GENOME, records SCARS postmortems, and feeds bounded evidence into MOLT/Evidence Maturity without automatic production promotion.

**Architecture:** Keep provider-specific response handling inside ECHOSENSE/SportsGameOdds, normalize into Goji-owned result contracts, validate with postgame CARAPACE, grade through family-specific evaluators, then orchestrate AUDIT or LIVE behavior through a single postgame runner. GENOME remains canonical for review state, settlement, experience events, append-only postmortems, hypotheses, and evidence; GitHub Actions only schedules and invokes the runner.

**Tech Stack:** Python 3.11, `requests`, `pytest`, GitHub Actions, Supabase/Postgres RPCs, SportsGameOdds v2 `/events` API.

**Spec:** `docs/superpowers/specs/2026-09-16-goji-v0.3-postgame-intelligence.md`

## Global Constraints

- Preserve the frozen pregame record; postgame code never mutates it.
- Provider-specific schema ends at the SportsGameOdds adapter.
- Settlement core is sport-agnostic; initial live validation is MLB and CFB.
- Require SportsGameOdds `status.finalized == true` before a result is settleable.
- Team grading uses verified final score; player-prop grading prefers the market-specific `odds.<oddID>.score` and requires `scoringSupported`.
- Missing player/market score evidence is not zero and must not be inferred.
- `genome_settle(...)` remains the only canonical settlement write.
- `prediction_postmortems` remains append-only canonical SCARS storage.
- AUDIT mode performs zero settlement/review/postmortem/hypothesis/evidence writes.
- LIVE mode writes only after explicit configuration enables it.
- Identical retries are idempotent; conflicting canonical writes are surfaced, never overwritten.
- Evidence Maturity stays multi-dimensional; no single opaque maturity score.
- MOLT cannot directly change REACTOR, SPINES, THERMAL, ROAR, or other production behavior.
- Human approval remains required for production promotion.
- Preserve Python 3.11 compatibility and all existing v0.2 tests.

from typing import Any

from .models import MarketResult, Provenance, ResolvedOutcome


def _number(value: Any) -> float | None:
    if isinstance(value, bool) or not isinstance(value, (int, float)):
        return None
    return float(value)


def parse_sgo_result(row: dict[str, Any]) -> ResolvedOutcome:
    event_id = str(row["eventID"])
    teams = row["teams"]
    status = row.get("status") or {}
    scores = row.get("scores") or {}
    odds = row.get("odds") or {}

    market_results: dict[str, MarketResult] = {}
    for key, market in odds.items():
        if not isinstance(market, dict):
            continue
        odd_id = str(market.get("oddID") or key)
        market_results[odd_id] = MarketResult(
            odd_id=odd_id,
            score=_number(market.get("score")),
            scoring_supported=market.get("scoringSupported") is True,
        )

    return ResolvedOutcome(
        provider_event_id=event_id,
        game_id=event_id,
        sport=str(row.get("leagueID") or "UNKNOWN"),
        finalized=status.get("finalized") is True,
        home_team=str(teams["home"]["names"]["long"]),
        away_team=str(teams["away"]["names"]["long"]),
        home_score=_number(scores.get("home")),
        away_score=_number(scores.get("away")),
        market_results=market_results,
        players=dict(row.get("players") or {}),
        provenance=Provenance(
            provider="SportsGameOdds",
            source_id=event_id,
            observed_at=datetime.now(timezone.utc),
        ),
        raw_reference={
            "status": dict(status),
            "score_keys": sorted(scores.keys()),
            "market_ids": sorted(market_results.keys()),
        },
    )

        if not event_ids:
            return []

            response = self.session.get(

            response.raise_for_status()
            payload = response.json()
        except (requests.RequestException, ValueError) as exc:
            raise SportsGameOddsError(f"SportsGameOdds finalized events request failed: {type(exc).__name__}") from exc

        rows = payload.get("data") if isinstance(payload, dict) else None
        if not isinstance(rows, list):
            raise SportsGameOddsError("SportsGameOdds finalized events response missing data list")

from typing import Any

from .models import ResolvedOutcome, ValidationState


class PostgameCarapace:
    def evaluate(
        self,
        result: ResolvedOutcome,
        frozen: dict[str, Any],
        *,
        provider_odd_id: str | None = None,
    ) -> ValidationState:
        reasons: list[str] = []
        decision = "PASS"

        if not result.finalized:
            return ValidationState("BLOCKED", ("event is not finalized",))
        if result.provenance.provider == "" or result.provenance.source_id == "":
            return ValidationState("BLOCKED", ("result provenance is missing",))
        if frozen.get("game_id") != result.game_id:
            return ValidationState("REVIEW_REQUIRED", ("game identity mismatch",))
        if frozen.get("sport") != result.sport:
            return ValidationState("REVIEW_REQUIRED", ("sport identity mismatch",))

        prediction_type = frozen.get("prediction_type")
        if prediction_type == "TEAM":
            if result.home_score is None or result.away_score is None:
                decision = "REVIEW_REQUIRED"
                reasons.append("final team score is incomplete")
        elif prediction_type == "PLAYER_PROP":
            if not provider_odd_id:
                decision = "REVIEW_REQUIRED"
                reasons.append("provider market id is missing")
            else:
                market = result.market_results.get(provider_odd_id)
                if market is None or not market.scoring_supported or market.score is None:
                    decision = "REVIEW_REQUIRED"
                    reasons.append("exact supported market score is unavailable")
        else:
            decision = "REVIEW_REQUIRED"
            reasons.append("unsupported prediction type")

        return ValidationState(decision, tuple(reasons))
```

from typing import Any

from .models import ResolvedOutcome, SettlementDecision


class TeamSettlementEvaluator:
    version = "team-v1"

    def evaluate(self, frozen: dict[str, Any], result: ResolvedOutcome) -> SettlementDecision:
        if result.home_score is None or result.away_score is None:
            return SettlementDecision("REVIEW_REQUIRED", "final score unavailable", {}, self.version)
        if result.home_score == result.away_score:
            return SettlementDecision("PUSH", "final score tied", {"home": result.home_score, "away": result.away_score}, self.version)

        winner = result.home_team if result.home_score > result.away_score else result.away_team
        selection = str(frozen.get("selection") or "")
        if selection not in {result.home_team, result.away_team}:
            return SettlementDecision("REVIEW_REQUIRED", "selection does not match result teams", {}, self.version)
        outcome = "WIN" if selection == winner else "LOSS"
        return SettlementDecision(
            outcome,
            f"selected {selection}; winner {winner}",
            {"home_team": result.home_team, "away_team": result.away_team, "home_score": result.home_score, "away_score": result.away_score},
            self.version,
        )


class PlayerPropSettlementEvaluator:
    version = "player-prop-v1"

    def evaluate(self, frozen: dict[str, Any], result: ResolvedOutcome) -> SettlementDecision:
        inputs = frozen.get("inputs") or {}
        odd_id = inputs.get("provider_odd_id")
        line = inputs.get("line")
        side = str(inputs.get("side") or "").upper()
        if not odd_id or isinstance(line, bool) or not isinstance(line, (int, float)) or side not in {"OVER", "UNDER"}:
            return SettlementDecision("REVIEW_REQUIRED", "prop grading identity is incomplete", {}, self.version)

        market = result.market_results.get(str(odd_id))
        if market is None or not market.scoring_supported or market.score is None:
            return SettlementDecision("REVIEW_REQUIRED", "supported market score unavailable", {"provider_odd_id": odd_id}, self.version)

        score = float(market.score)
        line = float(line)
        if score == line:
            outcome = "PUSH"
        elif side == "OVER":
            outcome = "WIN" if score > line else "LOSS"
        else:
            outcome = "WIN" if score < line else "LOSS"

        return SettlementDecision(
            outcome,
            f"{side} {line} graded against {score}",
            {"provider_odd_id": odd_id, "score": score, "line": line, "side": side},
            self.version,
        )
```

from typing import Any

from .models import ScarsDiagnosis


class Scars:
    def diagnose(
        self,
        *,
        prediction_id: str,
        frozen: dict[str, Any],
        settlement: dict[str, Any],
        observed: dict[str, Any],
    ) -> ScarsDiagnosis:
        outcome = settlement.get("outcome")
        unexpected = bool(observed.get("unexpected_event"))
        data_issue = bool(observed.get("data_issue"))
        expectation_match = observed.get("expectation_match")

        if expectation_match is True:
            expectation_quality = "GOOD"
        elif expectation_match is False:
            expectation_quality = "BAD"
        else:
            expectation_quality = "UNKNOWN"

        if data_issue:
            variance_class = "DATA_ISSUE"
            reasoning_quality = "UNKNOWN"
            learning_value = 0.1
        elif unexpected:
            variance_class = "UNEXPECTED_EVENT"
            reasoning_quality = "UNKNOWN"
            learning_value = 0.2
        elif expectation_quality == "GOOD":
            variance_class = "EXPECTED_VARIANCE" if outcome == "LOSS" else "UNKNOWN"
            reasoning_quality = "GOOD"
            learning_value = 0.8
        elif expectation_quality == "BAD":
            variance_class = "MODEL_MISS"
            reasoning_quality = "BAD"
            learning_value = 0.7 if outcome == "LOSS" else 0.4
        else:
            variance_class = "UNKNOWN"
            reasoning_quality = "UNKNOWN"
            learning_value = 0.2

        informative = "HIGH" if learning_value >= 0.7 else "MEDIUM" if learning_value >= 0.4 else "LOW"
        eligible = learning_value >= 0.4 and not data_issue and not unexpected
        memory_id = f"scars:{prediction_id}"
        correction = {}
        if reasoning_quality == "BAD":
            correction = {
                "family": observed.get("failure_family") or "general_reasoning",
                "statement": observed.get("correction_statement") or "Frozen expectation repeatedly requires review",
            }

        payload = {
            "game_id": frozen.get("game_id"),
            "sport": frozen.get("sport"),
            "expected_state": {"features": frozen.get("features") or {}, "context": frozen.get("context") or {}},
            "actual_state": settlement.get("actual_state") or {},
            "deltas": observed.get("deltas") or {},
            "primary_failure": observed.get("failure_family"),
            "secondary_factors": observed.get("secondary_factors") or [],
            "data_quality": observed.get("data_quality") or {},
            "confidence_assessment": {"frozen_probability": frozen.get("model_probability")},
            "calibration_assessment": {},
            "segment": {"prediction_type": frozen.get("prediction_type"), "market_key": frozen.get("market_key")},
            "evidence": observed,
            "provenance": settlement.get("provenance") or {},
            "causal_confidence": min(1.0, learning_value),
            "correction_hypothesis": correction,
            "evolve_action": {"action": "PROPOSE_ONLY"},
            "expectation_quality": expectation_quality,
            "reasoning_quality": reasoning_quality,
            "outcome_informativeness": informative,
            "variance_class": variance_class,
            "learning_value": learning_value,
            "eligible_for_pattern_learning": eligible,
            "learning_notes": {"outcome": outcome},
        }
        return ScarsDiagnosis(memory_id, prediction_id, expectation_quality, reasoning_quality, informative, variance_class, learning_value, eligible, payload)

import hashlib
from typing import Any

from .models import MoltProposal, ScarsDiagnosis


class Molt:
    def propose(self, diagnosis: ScarsDiagnosis, frozen: dict[str, Any]) -> MoltProposal | None:
        correction = diagnosis.payload.get("correction_hypothesis") or {}
        statement = str(correction.get("statement") or "").strip()
        family = str(correction.get("family") or "").strip()
        if not diagnosis.eligible_for_pattern_learning or diagnosis.learning_value < 0.4 or not statement or not family:
            return None

        sport = str(frozen.get("sport") or "UNKNOWN")
        prediction_type = str(frozen.get("prediction_type") or "UNKNOWN")
        segment_key = str(frozen.get("market_key") or "default")
        digest = hashlib.sha256(f"{sport}|{prediction_type}|{segment_key}|{family}|{statement}".encode()).hexdigest()[:20]
        hypothesis_id = f"molt:{digest}"

        hypothesis_payload = {
            "hypothesis_id": hypothesis_id,
            "sport": sport,
            "prediction_type": prediction_type,
            "segment_key": segment_key,
            "hypothesis": statement,
            "scope": {"failure_family": family},
            "lifecycle_status": "OBSERVED",
            "human_approval_required": True,
        }
        evidence_payload = {
            "p_hypothesis_id": hypothesis_id,
            "p_prediction_id": diagnosis.prediction_id,
            "p_postmortem_memory_id": diagnosis.memory_id,
            "p_evidence_family": family,
            "p_evidence_direction": "SUPPORTS",
            "p_learning_value": diagnosis.learning_value,
            "p_independent_group_key": str(frozen.get("independent_group_key") or diagnosis.prediction_id),
            "p_context": {"sport": sport, "prediction_type": prediction_type, "segment_key": segment_key},
            "p_notes": {"expectation_quality": diagnosis.expectation_quality, "reasoning_quality": diagnosis.reasoning_quality},
        }
        return MoltProposal(hypothesis_payload, evidence_payload)

Create `goji/postgame.py` with this control flow:

```python
from typing import Any

from .genome import GenomeClient
from .models import PostgameItem, PostgameRunReport
from .molt import Molt
from .postgame_carapace import PostgameCarapace
from .scars import Scars
from .settlement import PlayerPropSettlementEvaluator, TeamSettlementEvaluator
from .sportsgameodds import SportsGameOddsClient, SportsGameOddsError


class OperationalPostgame:
    def __init__(self, *, genome=None, provider=None, carapace=None, scars=None, molt=None):
        self.genome = genome or GenomeClient()
        self.provider = provider or SportsGameOddsClient()
        self.carapace = carapace or PostgameCarapace()
        self.scars = scars or Scars()
        self.molt = molt or Molt()
        self.team_evaluator = TeamSettlementEvaluator()
        self.prop_evaluator = PlayerPropSettlementEvaluator()

    def run(self, slate_id: str | None = None, *, mode: str = "AUDIT") -> PostgameRunReport:
        if mode not in {"AUDIT", "LIVE"}:
            raise ValueError("mode must be AUDIT or LIVE")
        rows = list(self.genome.review_queue(slate_id) or [])
        if not rows:
            return PostgameRunReport(slate_id, mode, (), 0, 0, 0, 0)

        event_ids = sorted({str(row["game_id"]) for row in rows})
        try:
            results = self.provider.finalized_events(event_ids)
        except SportsGameOddsError as exc:
            items = tuple(PostgameItem(str(row["prediction_id"]), "UNRESOLVED", str(exc), {}) for row in rows)
            return PostgameRunReport(slate_id, mode, items, 0, 0, 0, len(items))

        by_id = {result.game_id: result for result in results}
        items: list[PostgameItem] = []
        proposed = settled = reviews = unresolved = 0

        for row in rows:
            prediction_id = str(row["prediction_id"])
            result = by_id.get(str(row["game_id"]))
            if result is None:
                unresolved += 1
                items.append(PostgameItem(prediction_id, "UNRESOLVED", "provider returned no matching event", {}))
                continue

            frozen = dict(row.get("payload") or row)
            inputs = frozen.get("inputs") or {}
            odd_id = inputs.get("provider_odd_id")
            validation = self.carapace.evaluate(result, frozen, provider_odd_id=odd_id)
            if validation.decision == "BLOCKED":
                unresolved += 1
                items.append(PostgameItem(prediction_id, "UNRESOLVED", "; ".join(validation.reasons), {}))
                continue
            if validation.decision == "REVIEW_REQUIRED":
                reviews += 1
                payload = {"validation": validation.as_dict(), "result_source_id": result.provenance.source_id}
                items.append(PostgameItem(prediction_id, "REVIEW_REQUIRED", "; ".join(validation.reasons), payload))
                if mode == "LIVE":
                    self.genome.mark_review_required(prediction_id, row.get("slate_id"), "; ".join(validation.reasons), payload)
                continue

            evaluator = self.prop_evaluator if frozen.get("prediction_type") == "PLAYER_PROP" else self.team_evaluator
            decision = evaluator.evaluate(frozen, result)
            if decision.outcome == "REVIEW_REQUIRED":
                reviews += 1
                payload = {"grading_inputs": decision.grading_inputs, "evaluator_version": decision.evaluator_version}
                items.append(PostgameItem(prediction_id, "REVIEW_REQUIRED", decision.reason, payload))
                if mode == "LIVE":
                    self.genome.mark_review_required(prediction_id, row.get("slate_id"), decision.reason, payload)
                continue

            settlement_payload = {
                "outcome": decision.outcome,
                "game_id": result.game_id,
                "sport": result.sport,
                "grading_inputs": decision.grading_inputs,
                "evaluator_version": decision.evaluator_version,
                "provenance": {
                    "provider": result.provenance.provider,
                    "source_id": result.provenance.source_id,
                    "observed_at": result.provenance.observed_at.isoformat(),
                },
                "actual_state": {"home_score": result.home_score, "away_score": result.away_score},
            }
            proposed += 1
            items.append(PostgameItem(prediction_id, "PROPOSED" if mode == "AUDIT" else "SETTLED", decision.reason, settlement_payload))
            if mode == "LIVE":
                settlement_id = f"settle:{prediction_id}"
                self.genome.settle(settlement_id, prediction_id, settlement_payload, str(row["freeze_fingerprint"]))
                settled += 1

        return PostgameRunReport(slate_id, mode, tuple(items), proposed, settled, reviews, unresolved)
```
